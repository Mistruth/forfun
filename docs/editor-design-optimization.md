# 公众号长图编辑器设计优化方案

## 1. 项目目标

将现有编辑器优化为一个更专业、专注且高效的内容创作工作台，让用户能够清晰完成以下流程：

> 选择组件 → 编辑内容 → 调整样式 → 预览文章 → 导出图片

本次优化重点不是增加装饰效果，而是改善信息层级、操作效率、响应式体验和视觉一致性。

设计 Demo 已加入项目，可通过以下地址访问：

```text
http://localhost:8080/#/demo
```

---

## 2. 当前主要问题

### 2.1 工作流焦点分散

- 组件库、画布、配置面板和预览同时竞争注意力。
- 顶部工具栏按钮较多，主次关系不清晰。
- 预览按钮比最终目标“导出图片”更突出。

### 2.2 画布操作噪音较大

- 每个内容块右侧长期出现多枚纵向操作按钮。
- 组件标签、选中边框、配置提示和操作按钮同时出现。
- 操作控件容易压缩或遮挡 420px 的文章内容区域。

### 2.3 组件库扫描效率不高

- 两列小卡片没有提供足够的视觉预览价值。
- 预览和插入依赖多个小图标，点击目标较小。
- 缺少搜索、分类、最近使用和常用组件入口。

### 2.4 配置表单过长

- 所有属性从上到下平铺。
- 内容、排版、颜色、间距等字段没有形成清晰分组。
- 缺少字段恢复默认和组件整体重置能力。

### 2.5 预览空间利用率低

- 预览弹窗接近全屏，但文章仍然只有约 420px 宽。
- 两侧存在大量无效留白。
- 导出尺寸、格式、分段数量和进度不够直观。

### 2.6 移动端入口失配

- 当前路由只接入桌面编辑器。
- 在 390px 视口下，三栏布局无法正常使用。
- 画布会被组件库和配置面板挤出可视区域。

---

## 3. 总体设计方向

采用“专注型三栏工作台”：

| 区域 | 建议宽度 | 核心职责 |
| --- | --- | --- |
| 左侧组件库 | 240px | 搜索、筛选和插入组件 |
| 中间画布 | 自适应 | 编辑文章和管理内容块 |
| 右侧配置面板 | 320–360px | 编辑当前选中组件的属性 |

响应式策略：

- 大屏：完整三栏布局。
- 小于 1180px：隐藏常驻配置面板，需要时以抽屉打开。
- 小于 768px：使用“组件 / 画布 / 配置”底部 Tab，一次只显示一个工作区。

---

## 4. 模块设计方案

### 4.1 顶部工具栏

重新建立清晰的操作层级：

- 左侧：菜单、文档名称、自动保存状态。
- 中间：撤销、重做、画布缩放。
- 右侧：模板、预览、导出图片。
- “导出图片”作为当前视图唯一的主按钮。
- Schema 导入、Schema 导出和清空内容收纳到更多菜单。
- 自动保存使用稳定的内联状态，不依赖频繁 Toast。

### 4.2 组件库

- 增加组件搜索。
- 增加分类筛选。
- 使用单列紧凑列表，提高扫描效率。
- 点击整行直接插入组件。
- Hover 时显示插入提示，不长期展示多枚操作按钮。
- 后续增加“最近使用”和“常用组件”。
- 支持将组件拖拽到画布指定位置。

### 4.3 文章画布

- 保持微信公众号文章的固定内容宽度。
- 画布外部使用中性背景，突出白色文章页面。
- 选中组件时只保留轻量边框。
- 操作栏改为组件顶部的横向悬浮工具条。
- 操作包括拖拽、上移、下移、复制和删除。
- 在内容块之间显示“插入组件”按钮。
- 增加适应宽度、75% 和 100% 等缩放模式。
- 长文章后续增加大纲导航和快速跳转。

### 4.4 配置面板

配置项按语义分组：

1. 内容
2. 样式与排版
3. 颜色
4. 间距与布局
5. 图片与媒体
6. 高级设置

交互建议：

- 使用 Accordion 折叠低频设置。
- 支持单字段恢复默认值。
- 支持整个组件恢复默认设置。
- 数字参数支持输入和步进调节。
- 颜色提供预设与最近使用颜色。
- 面板顶部显示当前组件名称和更多操作。

### 4.5 模板选择

- 顶部提供搜索和分类。
- 桌面端采用“模板列表 + 模板预览”布局。
- 模板卡片保留名称、描述、块数量和更新时间。
- 编辑、历史版本和删除收纳到更多菜单。
- 应用模板前明确提示会替换当前内容。
- 可增加“应用到副本”，降低误覆盖风险。

### 4.6 预览与导出

- 预览窗口控制在合理宽度，不再无意义占满屏幕。
- 使用中性画布衬托白色文章页面。
- 提供适应宽度、100% 和手机宽度视图。
- 默认操作为“快速导出 PNG”。
- JPG、分段高度和压缩质量放入高级设置。
- 导出前显示预计宽度、图片数量和分段方式。
- 导出过程中显示进度。
- 完成后显示文件数量和最大文件大小。

### 4.7 空状态

编辑器为空时提供明确的起始操作：

- 选择模板开始。
- 插入正文。
- 导入 Schema。

避免只显示说明文字而不给出可执行入口。

### 4.8 移动端

- 使用底部“组件 / 画布 / 配置”Tab。
- 一次只展示一个核心工作区。
- 顶部只保留预览和导出等关键操作。
- 组件库、画布和配置面板都使用完整可用宽度。
- 移动端不得出现横向页面滚动。

### 4.9 可访问性

- 所有图标按钮提供 `aria-label`。
- Toggle 使用语义化 Switch。
- Dialog 支持 Esc 关闭和焦点返回。
- 所有核心操作支持键盘访问。
- Focus 状态使用统一的 `focus-visible` 样式。
- 选中状态在 Hover 时仍需保持可辨识。

---

## 5. 视觉规范

- 界面主体使用中性色，品牌绿色只用于关键操作和少量强调。
- 同一视图只保留一个主按钮。
- UI 字号以 `text-xs`、`text-sm` 和 `text-base` 为主。
- UI 字重只使用 `font-normal` 和 `font-medium`。
- 优先使用间距区分区域，减少不必要的边框和卡片。
- Hover 仅改变颜色或背景，不缩放、不增加阴影。
- 所有 App 外壳颜色使用设计 Token。
- 微信文章内容继续保持固定白底和独立的导出样式。

---

## 6. 实施优先级

### P0：核心体验

- 响应式布局和移动端工作区。
- 顶部工具栏重新分级。
- 内容块操作栏降噪。
- 配置面板字段分组。
- 撤销、重做和删除恢复。

### P1：效率提升

- 组件搜索、分类和最近使用。
- 模板可视化预览。
- 预览与导出流程重构。
- 键盘操作和无障碍补齐。

### P2：增强能力

- 文章大纲导航。
- 组件拖拽插入。
- 组件收藏和颜色预设。
- 暗色工作台模式。

## 7. Demo 已覆盖内容

当前 `/demo` 原型已经实现：

- 新的顶部工具栏层级。
- 可搜索、可分类的组件库。
- 轻量选中态与横向组件工具条。
- 内容块复制、移动和删除操作。
- 分组式配置面板。
- 预览和快速导出入口。
- 桌面三栏工作台。
- 移动端底部 Tab 工作区。
- 390px 移动视口无横向溢出。

Demo 用于确认设计方向，不代表已经替换现有生产编辑器。

---

## 8. 建议验收标准

- 用户能在 30 秒内找到并插入目标组件。
- 用户能明确识别当前选中的内容块。
- 一屏内只存在一个视觉主操作。
- 桌面、平板和移动端核心流程均可完成。
- 移动端不存在横向页面滚动。
- 删除内容后可以立即撤销。
- 导出前能够确认格式、尺寸和分段数量。
- 所有图标按钮都具有可访问名称。
- 键盘可以完成选择组件、编辑和打开预览等核心流程。
